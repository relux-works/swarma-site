## How to read the table

The book describes the platform in finished form, in the present tense: this is how it is built by design. The development state of each part is collected in one chapter, and each state there refers to a named capability and its boundary. These states do not add up to one percentage of readiness.

The second column of the table refers to the path described in the chapter and to the conditions under which it has been checked. The third column names the next boundary. Rows standing next to each other do not mean that their integration has been checked.

Open questions are collected in the same chapter of the book.
