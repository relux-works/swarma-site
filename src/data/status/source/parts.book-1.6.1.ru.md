# Swarma book

- Version: 1.6.1
- Chapter: 30, Где мы и что дальше
- Section: Состояние по частям платформы


Каждая строка этого раздела называет часть платформы, её предмет и статус. Статус берётся из словаря:

| Статус | Основание |
| --- | --- |
| работает сегодня | Есть в коде и используется в названных условиях. |
| решено | Владельцы приняли решение; это не свидетельство работающего кода. |
| спецификация | Описано в спецификации модуля; это не свидетельство реализации. |
| предложено | Архитектурное предложение ожидает решения. |
| открыто | Вопрос не решён. |

Где состояние не сводится к одному слову словаря, столбец "Статус" приводит точную формулировку в кавычках. Её читают буквально, и она не означает статуса выше сказанного в ней. Если у части несколько состояний, у неё несколько строк, и каждая строка верна для своего предмета. Строки сгруппированы по частям платформы: сначала Runtime, затем Protocol и Chain.
