# Product web design contract

- Archetype: documentation skeleton for the Swarma website.
- Primary audience: readers of the Russian book; English counterparts follow when authored.
- First viewport: page title, navigation and a single preparation notice.
- Evidence: the verbatim layer map from book 1.6.1, chapter 29, on the status route.
- Palette: unchanged shared semantic tokens; no product accent override.
- Density: readable unframed content; wrapping navigation instead of a menu overlay.
- Motion: none. System light, dark, increased contrast and forced colors use the shared tokens.
- Operator relationship: plain Relux Works footer text as required for this skeleton, with no logo assets.
- Assets: no remote fonts or media; the shared font stacks use system fallbacks until licensed fonts are supplied.
- Locales and directions: Russian LTR first; English LTR only when a counterpart file exists.
- Validation: static route, language, landmark, navigation, provenance and data checks; viewport and assistive technology release validation remains separate.
- Intentional deviations: minimal wrapping header, text attribution and no identity artwork; full visual components belong to the subsequent design work.

This skeleton makes no accessibility conformance claim. The full browser, visual and screen-reader release matrix must be observed before public release.
